🔐 ¿Dónde está el Secret?

DojoConf Security Challenge

```
```

Misión

Una aplicación empresarial asegura que sus credenciales están protegidas y que ningún secreto se encuentra expuesto.

Tu objetivo es analizar la arquitectura de la aplicación y descubrir cómo obtiene acceso a sus servicios internos.

🎯 Objetivo

Identifica dónde reside el secreto, cómo es utilizado por la aplicación y evalúa si el modelo actual cumple con principios modernos de seguridad.

🔎 Puntos de análisis

  • 💻 Revisa el código fuente
    Analiza la lógica de la aplicación y busca referencias a configuraciones sensibles.
  • 🌎 Busca variables de entorno
    Los secretos pueden ser entregados a la aplicación durante el proceso de ejecución.
  • 🐳 Analiza Docker
    Revisa imágenes, contenedores y archivos de despliegue. Los secretos pueden quedar incluidos accidentalmente.
  • ☸️ Inspecciona Kubernetes
    Observa cómo las aplicaciones reciben configuraciones y credenciales.
  • 🔐 Sigue el flujo del secreto
    Descubre cómo la aplicación obtiene la información que necesita para autenticarse.

💡 Pistas

Pista 1:
Antes de analizar la infraestructura, revisa qué información está disponible desde la propia aplicación.

Pista 2:
Existe una sección donde puedes revisar información sobre el código utilizado por esta aplicación.

Pista 3:
Busca rutas, archivos o recursos adicionales publicados por la aplicación.

Pista 4:
Los nombres de variables pueden revelar mucho: KEY, TOKEN, PASSWORD, SECRET.

Pista 5:
Pregunta clave: ¿El secreto está protegido o solamente está oculto?

Recuerda:

Encontrar un secreto no significa romper una aplicación. Muchas veces el mayor riesgo está en cómo las organizaciones almacenan y distribuyen sus credenciales.
