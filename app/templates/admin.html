⚠️ Lección aprendida:

Nunca almacenes contraseñas, tokens o llaves API directamente dentro del código fuente.

🥋 DojoConf Security Lesson

Código público no significa secretos públicos.

Las aplicaciones deben separar la lógica del código de los secretos utilizados en producción.

La solución no es esconder mejor el secreto. La solución es eliminarlo del código.
